# question-set Specification

## Purpose

格付けチェックで出題する 1 セットの問題データの形式と検証規則を定め、参加者に渡してよい公開形（正解情報を含まない形）を定義する。

## Requirements

### Requirement: 写真の指定と公開名
各選択肢は写真 `image` として、問題データ用の画像フォルダ内のファイル名を指定しなければならない（MUST）。指定したファイルは存在しなければならない（MUST）。写真はファイルの中身から作った名前で公開し、公開される URL は元のファイル名を含んではならない（MUST NOT）。指定されていない画像は公開しない。

#### Scenario: 指定した写真がない選択肢は検証に失敗する
- **WHEN** 画像フォルダに存在しない `ボルドー.jpg` を `image` に指定した選択肢を含む問題セットを検証する
- **THEN** 検証は失敗し、見つからないファイル名 `ボルドー.jpg` がエラーで示される

#### Scenario: 写真は元のファイル名を含まない URL で公開される
- **WHEN** `image` に `ボルドー.jpg` を指定した問題セットでアプリをビルドする
- **THEN** その写真の公開 URL は `ボルドー` を含まず、拡張子は `.jpg` のままである

#### Scenario: 指定されていない画像は公開されない
- **WHEN** 画像フォルダに、どの選択肢も指定していない `下書き.jpg` がある状態でアプリをビルドする
- **THEN** ビルド成果物に `下書き.jpg` の中身の画像は含まれない

### Requirement: 問題名と説明に正解情報を含めない
問題セットのタイトルとルールとランクと景品、各問題の問題名と説明、各選択肢の選択肢の説明は、問題セット内のどの問題の解説の文字列も、どの写真の元のファイル名（拡張子を除く）も含んではならない（MUST NOT）。これらは参加者に公開されるため。

#### Scenario: 説明に解説を含む問題は検証に失敗する
- **WHEN** 説明に、いずれかの問題の解説と同じ文字列を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題と含まれていた文字列がエラーで示される

#### Scenario: 問題名に別の問題の解説を含む問題は検証に失敗する
- **WHEN** 問題名に、別の問題の解説と同じ文字列を含む問題セットを検証する
- **THEN** 検証は失敗する

#### Scenario: タイトルに解説を含む問題セットは検証に失敗する
- **WHEN** タイトルに、いずれかの問題の解説と同じ文字列を含む問題セットを検証する
- **THEN** 検証は失敗し、タイトルの項目と含まれていた文字列がエラーで示される

#### Scenario: ルールに写真のファイル名を含む問題セットは検証に失敗する
- **WHEN** ルールに、いずれかの写真の元のファイル名（拡張子を除く）を含む問題セットを検証する
- **THEN** 検証は失敗し、該当するルールの項目と含まれていた文字列がエラーで示される

#### Scenario: 景品に写真のファイル名を含む問題セットは検証に失敗する
- **WHEN** 景品に、いずれかの写真の元のファイル名（拡張子を除く）を含む問題セットを検証する
- **THEN** 検証は失敗し、該当するランクの景品の項目と含まれていた文字列がエラーで示される

#### Scenario: 選択肢の説明に解説を含む問題は検証に失敗する
- **WHEN** 選択肢の説明に、いずれかの問題の解説と同じ文字列を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題・選択肢と含まれていた文字列がエラーで示される

#### Scenario: 選択肢の説明に銘柄を書いた問題は検証を通る
- **WHEN** 選択肢の説明が「シャトー・マルゴー」で、解説と写真のファイル名を含まない問題セットを検証する
- **THEN** この規則の検証は成功する

#### Scenario: 選択肢の説明に写真のファイル名を含む問題は検証に失敗する
- **WHEN** `image` が `ボルドー.jpg` の問題セットで、選択肢の説明が「フランス・ボルドーの赤ワイン」である問題を検証する
- **THEN** 検証は失敗し、該当する問題・選択肢と含まれていた文字列 `ボルドー` がエラーで示される

#### Scenario: 正解情報を含まない問題名と説明は検証を通る
- **WHEN** タイトルと説明が「高いワインはどちら？」、選択肢の説明が「フランス産の赤ワイン」のように解説の文字列と写真のファイル名を含まない問題セットを検証する
- **THEN** この規則の検証は成功する

### Requirement: 参加者向けの公開形
システムは問題セットから、タイトルと、ルールと、ランクと景品と、各問題の出題形式・問題名・説明と、各選択肢の写真・選択肢の説明だけを表示順に含む公開形を作らなければならない（MUST）。公開形はラベル・`rank`・解説を含んではならない（MUST NOT）。

#### Scenario: 公開形は rank を含まない
- **WHEN** 問題セットを公開形に変換する
- **THEN** どの選択肢にも `rank` の項目が存在しない

#### Scenario: 公開形はラベルを含まない
- **WHEN** 問題セットを公開形に変換する
- **THEN** どの選択肢にも `label` の項目が存在しない

#### Scenario: 公開形は解説を含まない
- **WHEN** 問題セットを公開形に変換する
- **THEN** どの問題にも解説の項目が存在しない

#### Scenario: 公開形は出題順と表示項目を保つ
- **WHEN** 3 問の問題セットを公開形に変換する
- **THEN** 公開形は元と同じタイトルと、同じ順の 3 問を持ち、各問題の出題形式・問題名・説明と、各選択肢の写真・選択肢の説明は元の値と表示順で一致する

### Requirement: 選択肢の数と作者が付けるラベル
各問題の選択肢は 2 個または 3 個でなければならない（MUST）。各選択肢のラベルは作者が `A`・`B`・`C` のいずれかで書き、選択肢数を n として `A` から n 番目の文字までを 1 回ずつ使わなければならない（MUST）。ラベルは選択肢を書いた順（表示順）と無関係に決まる。

#### Scenario: 選択肢が 1 個の問題は検証に失敗する
- **WHEN** 選択肢が 1 個の問題を含む問題セットを検証する
- **THEN** 検証は失敗する

#### Scenario: 選択肢が 4 個の問題は検証に失敗する
- **WHEN** 選択肢が 4 個の問題を含む問題セットを検証する
- **THEN** 検証は失敗する

#### Scenario: ラベルがない選択肢は検証に失敗する
- **WHEN** `label` を書いていない選択肢を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題・選択肢と `label` の項目がエラーで示される

#### Scenario: A・B・C 以外のラベルは検証に失敗する
- **WHEN** ラベルが `D` の選択肢を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題・選択肢と `label` の項目がエラーで示される

#### Scenario: ラベルが重複する問題は検証に失敗する
- **WHEN** 2 択の問題のラベルが A と A である問題セットを検証する
- **THEN** 検証は失敗し、該当する問題がエラーで示される

#### Scenario: 選択肢数を超えるラベルを使う問題は検証に失敗する
- **WHEN** 2 択の問題のラベルが A と C である問題セットを検証する
- **THEN** 検証は失敗し、該当する問題がエラーで示される

#### Scenario: ラベルは書いた値になり表示順は書いた順になる
- **WHEN** 3 択の問題で、選択肢を B・C・A のラベルの順に書いて検証する
- **THEN** 1 番目・2 番目・3 番目の選択肢はその順のまま、ラベルはそれぞれ B・C・A になる

### Requirement: 問題セットの形式
問題セットは会のタイトルと、1 つ以上の問題を出題順に並べたものを持たなければならない（MUST）。タイトルは空にできない。ゲームのルール `rules` は省略でき、書くときは空でない文字列のリストにする。省略したルールは 0 個として扱う。ランクと景品 `prizes` も省略でき、書くときは各要素がランク `rank`・条件 `condition`・景品 `prize`（どれも空にできない）を持つリストにし、上のランクから並べる。各問題は問題名、説明、解説、選択肢 2〜3 個を持つ。選択肢は画面に表示する順に並べる。各選択肢はラベル `label`、写真 `image`、選択肢の説明 `note`、順位 `rank` を持つ。選択肢の説明は発表前から参加者に見えるので、銘柄を見せるときはここに書く。

#### Scenario: 正しい問題セットは検証を通る
- **WHEN** タイトルと、2 択の問題と 3 択の問題を含む、全項目が揃った問題セットを検証する
- **THEN** 検証は成功する

#### Scenario: ルールは書いた順に読み、省略すると 0 個になる
- **WHEN** ルールを 2 個書いた問題セットと、ルールを書かない問題セットを検証する
- **THEN** 前者のルールは書いた順の 2 個、後者のルールは 0 個になる

#### Scenario: ランクと景品は書いた順に読み、省略すると 0 個になる
- **WHEN** ランクと景品を 2 つ書いた問題セットと、書かない問題セットを検証する
- **THEN** 前者のランクと景品は書いた順の 2 つ、後者は 0 個になる

#### Scenario: 景品が空のランクは検証に失敗する
- **WHEN** 景品が空文字のランクを含む問題セットを検証する
- **THEN** 検証は失敗し、該当するランクの景品の項目がエラーで示される

#### Scenario: 空のルールを含む問題セットは検証に失敗する
- **WHEN** 空文字のルールを含む問題セットを検証する
- **THEN** 検証は失敗し、該当するルールの項目がエラーで示される

#### Scenario: タイトルがない問題セットは検証に失敗する
- **WHEN** タイトルを書いていない問題セットを検証する
- **THEN** 検証は失敗し、タイトルの項目がエラーで示される

#### Scenario: タイトルが空の問題セットは検証に失敗する
- **WHEN** タイトルが空文字または空白だけの問題セットを検証する
- **THEN** 検証は失敗し、タイトルの項目がエラーで示される

#### Scenario: 問題が 0 件の問題セットは検証に失敗する
- **WHEN** 問題を 1 件も含まない問題セットを検証する
- **THEN** 検証は失敗する

#### Scenario: 問題名・説明・解説が空の問題は検証に失敗する
- **WHEN** 問題名、説明、解説のいずれかが空文字または空白だけの問題を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題と項目がエラーで示される

#### Scenario: 写真が空の選択肢は検証に失敗する
- **WHEN** 写真が空文字または空白だけの選択肢を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題・選択肢と項目がエラーで示される

#### Scenario: 選択肢の説明が空の選択肢は検証に失敗する
- **WHEN** 選択肢の説明が空文字または空白だけの選択肢を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題・選択肢と項目がエラーで示される

#### Scenario: 選択肢の説明がない選択肢は検証に失敗する
- **WHEN** `note` を書いていない選択肢を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題・選択肢と `note` の項目がエラーで示される

#### Scenario: 複数の誤りはまとめて報告される
- **WHEN** rank の重複、写真の欠落、空の解説を 1 つずつ含む問題セットを検証する
- **THEN** 検証は失敗し、3 件すべてがエラーで示される

### Requirement: 選択肢の順位と正解
各問題の選択肢の `rank` は、選択肢数を n として 1〜n を重複なく 1 回ずつ使わなければならない（MUST）。`rank: 1` は最も高価な選択肢を表し、これが正解である。

#### Scenario: rank 1 がない問題は検証に失敗する
- **WHEN** 2 択の問題の `rank` が 2 と 3 である問題セットを検証する
- **THEN** 検証は失敗する

#### Scenario: rank が重複する問題は検証に失敗する
- **WHEN** 3 択の問題の `rank` が 1、1、2 である問題セットを検証する
- **THEN** 検証は失敗する

#### Scenario: 正解は rank 1 の選択肢になる
- **WHEN** 選択肢 B の `rank` が 1 である
- **THEN** その問題の正解は B と判定される
