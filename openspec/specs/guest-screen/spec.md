# guest-screen Specification

## Purpose

参加者が自分のスマホで、司会の進行に合わせて問題と選択肢の写真、正解発表を見るための画面を定める。正解情報は、司会が正解発表をした問題の分だけを届ける。

## Requirements

### Requirement: 正解情報を表示しない
参加者画面は、会場が正解発表をしていない間、ラベル・正解の赤枠・解説を表示してはならない（MUST NOT）。ラベルの帯、ラベルを持つ属性、ラベルを含む代替テキストも画面に置いてはならない（MUST NOT）。参加者画面は正解発表の操作を持ってはならない（MUST NOT）。

#### Scenario: どの問題でも正解情報が表示されない
- **WHEN** 司会画面が正解発表をせずに第 1 問から最終問まで進む
- **THEN** 参加者画面のどの問題でも正解の赤枠・解説が表示されない

#### Scenario: どの問題でもラベルが表示されない
- **WHEN** 司会画面が正解発表をせずに第 1 問から最終問まで進む
- **THEN** 参加者画面のどの選択肢の要素にもラベルの帯（`.label-bar`）と `data-label` 属性がなく、写真の代替テキストがラベル（`選択肢 A` の形）を含まない

#### Scenario: 正解発表の操作がない
- **WHEN** 参加者画面を表示する
- **THEN** 正解発表のボタンは存在せず、Space キーや Enter キーを押しても正解情報は表示されない

### Requirement: 参加者に届くデータに正解情報を含めない
参加者画面を表示するためにブラウザへ届くデータ（HTML、JavaScript、画面のデータ取得の応答、会場から届く状態）は、会場が正解発表をした問題を除き、どの選択肢のラベルも、どの問題の `rank`・解説も含んではならない（MUST NOT）。HTML と JavaScript は、どの問題の正解情報も含んではならない（MUST NOT）。

#### Scenario: 参加者画面を進める間に受け取る応答に正解情報を含まない
- **WHEN** 参加者画面を開き、司会画面が正解発表をせずに第 1 問から最終問まで進む
- **THEN** その間に参加者のブラウザが受け取ったどの応答と WebSocket のフレームにも、問題セットのどの問題の解説の文字列も含まれない

#### Scenario: 参加者に届くデータの選択肢は順位を持たない
- **WHEN** 参加者画面が表示に使う問題データを取り出す
- **THEN** どの選択肢も写真と選択肢の説明だけを持ち、`rank` を持たない

#### Scenario: 参加者に届くデータの選択肢はラベルを持たない
- **WHEN** 参加者画面が表示に使う問題データを取り出す
- **THEN** どの選択肢も `label` を持たない

#### Scenario: 参加者画面の HTML に正解情報を含まない
- **WHEN** 参加者画面の HTML を取得する
- **THEN** HTML には、問題セットのどの問題の解説の文字列も含まれない

#### Scenario: 参加者画面が読み込む JavaScript に正解情報を含まない
- **WHEN** 参加者画面が読み込むすべての JavaScript を取得する
- **THEN** そのどれにも、問題セットのどの問題の解説の文字列も含まれない

### Requirement: スマホでの表示
参加者画面は幅 360px のスマホで、横スクロールなしに表示できなければならない（MUST）。正解発表の表示も同じとする。

#### Scenario: 幅 360px で横スクロールが発生しない
- **WHEN** 幅 360px のビューポートで 3 択の問題を表示する
- **THEN** ページの横スクロールは発生せず、全選択肢の写真と選択肢の説明が縦スクロールで見られる

#### Scenario: 幅 360px で正解発表が横スクロールなしに見られる
- **WHEN** 幅 360px のビューポートで 3 択の問題の正解発表を表示する
- **THEN** ページの横スクロールは発生せず、全選択肢のラベルと解説が縦スクロールで見られる

### Requirement: 問題画面の表示
参加者画面は会場が表示している問題について、問題番号（「STAGE 1」の形）、問題名、説明、各選択肢の写真と選択肢の説明を表示順に表示しなければならない（MUST）。

#### Scenario: 第 1 問を問題番号つきで表示する
- **WHEN** 司会画面がタイトル画面から第 1 問へ進む
- **THEN** 参加者画面に第 1 問の問題名・説明・全選択肢の写真と選択肢の説明が表示順に、および「STAGE 1」が表示される

#### Scenario: 3 択の問題で 3 つの選択肢を表示する
- **WHEN** 会場が選択肢 3 個の問題を表示する
- **THEN** 参加者画面に 3 つの選択肢が、問題データに書いた順に写真と選択肢の説明つきで表示される

### Requirement: 司会画面への追従
参加者画面は会場の進行状態に従って、タイトル画面・ルール画面・ランクと景品の画面・問題画面・正解発表を切り替えなければならない（MUST）。参加者画面は前へ・次へ・はじめるなど、表示する画面を変える操作を持ってはならない（MUST NOT）。会場の状態が届くまではタイトル画面を表示する。

#### Scenario: 司会がタイトル画面から進むと第 1 問を表示する
- **WHEN** ルールもランクと景品もない問題セットで、参加者画面がタイトル画面を表示している間に、司会画面で「次へ」を押す
- **THEN** 参加者画面は第 1 問を表示する

#### Scenario: 司会が前の問題に戻ると参加者画面も戻る
- **WHEN** 第 2 問で司会画面の「前へ」を押す
- **THEN** 参加者画面は第 1 問を表示する

#### Scenario: 移動の操作がない
- **WHEN** 参加者画面でタイトル画面と問題画面を表示する
- **THEN** どちらの画面にも前へ・次へ・はじめるのボタンがない

#### Scenario: 問題が切り替わると先頭までスクロールする
- **WHEN** 参加者画面を下までスクロールした状態で、司会画面が次の問題へ進む
- **THEN** 参加者画面は次の問題を先頭から表示する

### Requirement: 正解発表の表示
会場が正解発表中のとき、参加者画面はその問題について、各選択肢の写真の中央に大きなラベル、正解の赤枠、正解の並び（「正解は B」の形）、解説を表示しなければならない（MUST）。選択肢の位置は正解発表前と変えない。

#### Scenario: pick の正解発表で正解情報を表示する
- **WHEN** 司会画面が pick の問題で正解発表をする
- **THEN** 参加者画面の各選択肢にラベルが出て、`rank: 1` の選択肢に正解の赤枠が付き、正解ラベルと解説が表示される

#### Scenario: order の正解発表で正解の並びを表示する
- **WHEN** 司会画面が order の問題で正解発表をする
- **THEN** 参加者画面の全選択肢にラベルが表示され、正解の並びと解説が表示される

#### Scenario: 正解発表で選択肢の位置は変わらない
- **WHEN** 司会画面が正解発表をする
- **THEN** 参加者画面の各選択肢の写真は正解発表前と同じ位置にある

#### Scenario: 正解発表後に次の問題へ進むと正解情報を消す
- **WHEN** 正解発表を表示した後、司会画面が次の問題へ進む
- **THEN** 参加者画面の次の問題には正解情報とラベルが表示されない

### Requirement: 正解発表の演出
参加者画面は、つながっている間に正解発表が操作されたとき、司会画面と同じく選択肢のカードを左から順にめくり、最後の 1 枚をめくり終えてから正解の並びと解説を表示し、紙吹雪を再生しなければならない（MUST）。正解発表がもう一度操作されたときは、めくらずに紙吹雪を最初から再生し直す。つないだ時点ですでに正解発表中だったときと、reduced motion が有効なときは、めくらず紙吹雪も再生せず、正解情報をすぐに表示する。

#### Scenario: 正解発表で紙吹雪を再生する
- **WHEN** 参加者画面を開いている間に、司会画面で「正解発表」を押す
- **THEN** 参加者画面で紙吹雪が再生される

#### Scenario: めくり終えてから正解の並びと紙吹雪を出す
- **WHEN** 参加者画面を開いている間に、司会画面で「正解発表」を押す
- **THEN** 参加者画面の選択肢が左から 1 枚ずつめくれ、最後の 1 枚をめくり終えた後に正解の並びと解説が表示され紙吹雪が再生される

#### Scenario: 正解発表をもう一度押すと紙吹雪を再生し直す
- **WHEN** 正解発表をした問題で、司会画面がもう一度「正解発表」を押す
- **THEN** 参加者画面で紙吹雪が最初から再生される

#### Scenario: 正解発表中に開いたときは紙吹雪を再生しない
- **WHEN** 会場が正解発表中のときに参加者画面を新しく開く
- **THEN** 正解情報は表示され、紙吹雪は再生されない

#### Scenario: reduced motion が有効なときは紙吹雪を再生しない
- **WHEN** reduced motion が有効な参加者画面を開いている間に、司会画面で「正解発表」を押す
- **THEN** 紙吹雪は再生されず、正解情報は表示される

### Requirement: 接続が切れている間の表示
参加者画面は、会場との接続が切れている間と、開いてから 5 秒たっても会場につながらないとき、「再接続中」と表示しなければならない（MUST）。その間も最後に受け取った画面は表示したままにする。

#### Scenario: 接続が切れると再接続中と表示する
- **WHEN** 第 2 問を表示している参加者画面の接続が切れる
- **THEN** 第 2 問を表示したまま「再接続中」が表示される

#### Scenario: 最初につながらないときは再接続中と表示する
- **WHEN** 会場につながらない状態で参加者画面を開き、5 秒待つ
- **THEN** タイトル画面の上に「再接続中」が表示される

#### Scenario: 再接続すると再接続中の表示を消す
- **WHEN** 接続が切れた参加者画面が再接続する
- **THEN** 「再接続中」の表示が消える

### Requirement: ルールとランクと景品の表示
参加者画面は、会場の進行状態がルール画面またはランクと景品の画面のとき、ルールとランクと景品を 1 画面に並べて表示しなければならない（MUST）。ルールは見出しと全ルールを書いた順に番号付きで、ランクと景品は見出しと各ランクのランク・条件・景品を書いた順に表示する。書いていないほうは表示しない。

#### Scenario: 司会がルール画面へ進むと参加者画面はルールとランクと景品を表示する
- **WHEN** ルールとランクと景品のある問題セットで、参加者画面がタイトル画面を表示している間に、司会画面で「次へ」を押す
- **THEN** 参加者画面は全ルールと全ランクの景品を書いた順に表示する

#### Scenario: 司会がランクと景品の画面へ進んでも参加者画面は同じ表示のまま
- **WHEN** ルールとランクと景品のある問題セットで、司会画面がルール画面から「次へ」を押す
- **THEN** 参加者画面は全ルールと全ランクの景品を表示したままである

### Requirement: タイトル画面で司会を待つ
参加者画面は、会場の進行状態がタイトル画面のとき、問題セットのタイトルだけを表示するタイトル画面を表示しなければならない（MUST）。遊び方の説明と操作のボタンは表示しない。

#### Scenario: 会場がタイトル画面のときに開くとタイトル画面を表示する
- **WHEN** 会場の進行状態がタイトル画面のときに参加者画面を開く
- **THEN** 問題セットのタイトルが表示され、問題とボタンは表示されない

#### Scenario: 司会が始めるまでタイトル画面のまま
- **WHEN** 会場の進行状態がタイトル画面のまま、参加者画面で待つ
- **THEN** タイトル画面のままである

#### Scenario: タイトル画面に正解情報を表示しない
- **WHEN** タイトル画面を表示する
- **THEN** 正解の赤枠・解説はどれも表示されない
