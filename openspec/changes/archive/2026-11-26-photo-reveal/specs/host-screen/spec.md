# Spec Delta

## MODIFIED Requirements

### Requirement: 正解発表
正解発表をすると、司会画面は各選択肢を発表前と同じ位置に置いたまま、各選択肢の写真の中央にラベルを大きく表示し、`rank: 1` の選択肢の枠とラベルを赤（正解の赤枠）にし、ほかの選択肢を薄くし、正解ラベルと解説を表示しなければならない（MUST）。正解の選択肢は色だけでなく、選択肢のラベルと「正解は B」の文字でも区別できなければならない（MUST）。選択肢に「正解」の文字の印を重ねてはならない（MUST NOT）。写真当ての問題では、中央にラベルを重ねず、発表前と同じ左上のラベルを残し、各写真の下に誰の写真か（`caption`）を表示する。誰の写真かを出す行は発表前から同じ高さで空けておき、写真の位置と大きさを変えない。

#### Scenario: 正解発表で各選択肢にラベルを表示する
- **WHEN** 選択肢を B・A のラベルの順に書いた問題で「正解発表」を押す
- **THEN** 1 番目の選択肢に B、2 番目の選択肢に A のラベルが表示される

#### Scenario: 3 択の正解発表で各選択肢にラベルを表示する
- **WHEN** 選択肢を C・A・B のラベルの順に書いた問題で「正解発表」を押す
- **THEN** 1 番目・2 番目・3 番目の選択肢にそれぞれ C・A・B のラベルが表示される

#### Scenario: 正解発表で選択肢の位置は変わらない
- **WHEN** 「正解発表」を押す
- **THEN** 各選択肢の写真は発表前と同じ順で、発表前と同じ座標と大きさで表示される

#### Scenario: 正解の選択肢だけを正解の見た目にする
- **WHEN** 選択肢 B が `rank: 1` の問題で「正解発表」を押す
- **THEN** 選択肢 B だけに正解の赤枠が付き、どの選択肢にも「正解」の文字は重ならない

#### Scenario: 3 択で正解の選択肢だけを正解の見た目にする
- **WHEN** A、B、C の `rank` が 1、3、2 の問題で「正解発表」を押す
- **THEN** 選択肢 A だけに正解の赤枠が付き、どの選択肢にも「正解」の文字は重ならない

#### Scenario: 正解発表で正解ラベルと解説を表示する
- **WHEN** 選択肢 B が `rank: 1` の問題で「正解発表」を押す
- **THEN** 「正解は B」とその問題の解説が表示される

#### Scenario: 写真当ての正解発表では中央にラベルを重ねず、写真の下に誰の写真かを表示する
- **WHEN** 写真当ての問題で「正解発表」を押す
- **THEN** 各選択肢の写真の左上に問題データのとおりのラベルが残り、ラベルの帯（`.label-bar`）はなく、各写真の下にその選択肢の `caption` が表示される

### Requirement: 問題画面の表示
司会画面は現在の問題について、問題番号（「STAGE 1」の形）、問題名、説明、各選択肢の写真と選択肢の説明を表示順に表示しなければならない（MUST）。写真当てでない問題では、正解発表前に、どの写真がどのラベルかを読み取れる情報（ラベルの帯、ラベルを持つ属性、ラベルを含む代替テキスト）を画面に置いてはならない（MUST NOT）。写真当ての問題では、正解発表前から各写真の隅にラベルを表示し、写真の中央を隠さない。選択肢の説明は表示しない。

#### Scenario: 第 1 問を問題番号つきで表示する
- **WHEN** タイトル画面から第 1 問へ進む
- **THEN** 第 1 問の問題名・説明・全選択肢の写真と選択肢の説明が表示順に、および「STAGE 1」が表示される

#### Scenario: 正解発表前は正解情報を表示しない
- **WHEN** 問題を表示し、まだ正解発表をしていない
- **THEN** 正解の赤枠と解説はどちらも表示されない

#### Scenario: 正解発表後に移動して戻るとラベルを表示しない
- **WHEN** 第 1 問で正解発表をしてから「次へ」、続けて「前へ」を押す
- **THEN** どの選択肢の要素にもラベルの帯（`.label-bar`）と `data-label` 属性がなく、写真の代替テキストがラベル（`選択肢 A` の形）を含まない

#### Scenario: 正解発表前はラベルを表示しない
- **WHEN** 写真当てでない問題を表示し、まだ正解発表をしていない
- **THEN** どの選択肢の要素にもラベルの帯（`.label-bar`）と `data-label` 属性がなく、写真の代替テキストがラベル（`選択肢 A` の形）を含まない

#### Scenario: 写真当ての問題は正解発表前から各選択肢にラベルを表示する
- **WHEN** 写真当ての問題を表示し、まだ正解発表をしていない
- **THEN** 各選択肢の写真の左上に問題データのとおりのラベルが表示され、ラベルの帯（`.label-bar`）と選択肢の説明はなく、誰の写真かはまだ表示されない
