## ADDED Requirements

### Requirement: 正解発表の正解情報の表示
会場が正解発表中のとき、参加者画面はその問題について、各選択肢の写真の中央に大きなラベル、正解の赤枠、正解ラベル（「正解は B」の形）、解説を表示しなければならない（MUST）。選択肢の位置は正解発表前と変えない。

#### Scenario: 正解発表で正解情報を表示する
- **WHEN** 司会画面が正解発表をする
- **THEN** 参加者画面の各選択肢にラベルが出て、`rank: 1` の選択肢に正解の赤枠が付き、正解ラベルと解説が表示される

#### Scenario: 正解発表で選択肢の位置は変わらない
- **WHEN** 司会画面が正解発表をする
- **THEN** 参加者画面の各選択肢の写真は正解発表前と同じ位置にある

#### Scenario: 正解発表後に次の問題へ進むと正解情報を消す
- **WHEN** 正解発表を表示した後、司会画面が次の問題へ進む
- **THEN** 参加者画面の次の問題には正解情報とラベルが表示されない
