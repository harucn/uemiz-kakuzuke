# Spec Delta

## ADDED Requirements

### Requirement: 正解発表
正解発表をすると、司会画面は各選択肢を発表前と同じ位置に置いたまま、各選択肢の写真の中央にラベルを大きく表示し、`rank: 1` の選択肢の枠とラベルを赤（正解の赤枠）にし、ほかの選択肢を薄くし、正解ラベルと解説を表示しなければならない（MUST）。正解の選択肢は色だけでなく、選択肢のラベルと「正解は B」の文字でも区別できなければならない（MUST）。選択肢に「正解」の文字の印を重ねてはならない（MUST NOT）。

#### Scenario: 正解発表で各選択肢にラベルを表示する
- **WHEN** 選択肢を B・A のラベルの順に書いた問題で「正解発表」を押す
- **THEN** 1 番目の選択肢に B、2 番目の選択肢に A のラベルが表示される

#### Scenario: 3 択の正解発表で各選択肢にラベルを表示する
- **WHEN** 選択肢を C・A・B のラベルの順に書いた問題で「正解発表」を押す
- **THEN** 1 番目・2 番目・3 番目の選択肢にそれぞれ C・A・B のラベルが表示される

#### Scenario: 正解発表で選択肢の位置は変わらない
- **WHEN** 「正解発表」を押す
- **THEN** 各選択肢の写真は発表前と同じ順で、発表前と同じ座標と大きさで表示される

#### Scenario: 正解の選択肢だけを正解の見た目にする
- **WHEN** 選択肢 B が `rank: 1` の問題で「正解発表」を押す
- **THEN** 選択肢 B だけに正解の赤枠が付き、どの選択肢にも「正解」の文字は重ならない

#### Scenario: 3 択で正解の選択肢だけを正解の見た目にする
- **WHEN** A、B、C の `rank` が 1、3、2 の問題で「正解発表」を押す
- **THEN** 選択肢 A だけに正解の赤枠が付き、どの選択肢にも「正解」の文字は重ならない

#### Scenario: 正解発表で正解ラベルと解説を表示する
- **WHEN** 選択肢 B が `rank: 1` の問題で「正解発表」を押す
- **THEN** 「正解は B」とその問題の解説が表示される


## REMOVED Requirements

### Requirement: pick の正解発表
**Reason**: 出題形式が 1 つになり、pick と order を分ける必要がなくなった
**Migration**: 「正解発表」の要件に置き換える

### Requirement: order の正解発表
**Reason**: 高い順に並べる出題形式をやめた
**Migration**: 問題は rank 1 の選択肢を当てる形にし、正解発表は「正解発表」の要件に従う
