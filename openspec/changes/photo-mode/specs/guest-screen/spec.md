# Spec Delta

## REMOVED Requirements

### Requirement: 正解情報を表示しない
**Reason**: 写真当ての問題では正解発表前からラベルを出すので、「どの問題でもラベルが表示されない」が成り立たなくなる
**Migration**: 「正解発表前の表示」の要件に置き換える

## ADDED Requirements

### Requirement: 正解発表前の表示
参加者画面は、会場が正解発表をしていない間、正解の赤枠・解説を表示してはならない（MUST NOT）。写真当てでない問題では、ラベルも表示してはならず、ラベルの帯、ラベルを持つ属性、ラベルを含む代替テキストも画面に置いてはならない（MUST NOT）。写真当ての問題では、正解発表前から各写真の隅にラベルを表示する。参加者画面は正解発表の操作を持ってはならない（MUST NOT）。

#### Scenario: どの問題でも正解情報が表示されない
- **WHEN** 司会画面が正解発表をせずに第 1 問から最終問まで進む
- **THEN** 参加者画面のどの問題でも正解の赤枠・解説が表示されない

#### Scenario: 写真当て以外の問題ではラベルが表示されない
- **WHEN** 司会画面が正解発表をせずに第 1 問から最終問まで進む
- **THEN** 参加者画面の写真当てでない問題では、どの選択肢の要素にもラベルの帯（`.label-bar`）と `data-label` 属性がなく、写真の代替テキストがラベル（`選択肢 A` の形）を含まない

#### Scenario: 写真当ての問題は正解発表前から各選択肢にラベルを表示する
- **WHEN** 会場が写真当ての問題を表示し、まだ正解発表をしていない
- **THEN** 参加者画面の各選択肢の写真の左上に問題データのとおりのラベルが表示され、ラベルの帯（`.label-bar`）と選択肢の説明はない

#### Scenario: 正解発表の操作がない
- **WHEN** 参加者画面を表示する
- **THEN** 正解発表のボタンは存在せず、Space キーや Enter キーを押しても正解情報は表示されない

## MODIFIED Requirements

### Requirement: 参加者に届くデータに正解情報を含めない
参加者画面を表示するためにブラウザへ届くデータ（HTML、JavaScript、画面のデータ取得の応答、会場から届く状態）は、会場が正解発表をした問題を除き、写真当てでない問題のラベルも、どの問題の `rank`・解説も含んではならない（MUST NOT）。写真当ての問題のラベルは正解情報ではないので含めてよい。HTML と JavaScript は、どの問題の正解情報も含んではならない（MUST NOT）。

#### Scenario: 参加者画面を進める間に受け取る応答に正解情報を含まない
- **WHEN** 参加者画面を開き、司会画面が正解発表をせずに第 1 問から最終問まで進む
- **THEN** その間に参加者のブラウザが受け取ったどの応答と WebSocket のフレームにも、問題セットのどの問題の解説の文字列も含まれない

#### Scenario: 参加者に届くデータの選択肢は順位を持たない
- **WHEN** 参加者画面が表示に使う問題データを取り出す
- **THEN** どの選択肢も写真と選択肢の説明だけを持ち、`rank` を持たない

#### Scenario: 参加者に届くデータの選択肢はラベルを持たない
- **WHEN** 参加者画面が表示に使う問題データを取り出す
- **THEN** どの選択肢も `label` を持たない

#### Scenario: 参加者画面の HTML に正解情報を含まない
- **WHEN** 参加者画面の HTML を取得する
- **THEN** HTML には、問題セットのどの問題の解説の文字列も含まれない

#### Scenario: 参加者画面が読み込む JavaScript に正解情報を含まない
- **WHEN** 参加者画面が読み込むすべての JavaScript を取得する
- **THEN** そのどれにも、問題セットのどの問題の解説の文字列も含まれない

#### Scenario: 参加者に届くデータで、写真当て以外の問題はラベルを持たない
- **WHEN** 参加者画面が表示に使う問題データを取り出す
- **THEN** 写真当てでない問題のラベル列は空（null）で、写真当ての問題のラベル列は問題データの表示順のラベルと一致する

### Requirement: 問題画面の表示
参加者画面は会場が表示している問題について、問題番号（「STAGE 1」の形）、問題名、説明、各選択肢の写真と選択肢の説明を表示順に表示しなければならない（MUST）。写真当ての問題は選択肢の説明を持たないので、写真の下に何も表示しない。

#### Scenario: 第 1 問を問題番号つきで表示する
- **WHEN** 司会画面がタイトル画面から第 1 問へ進む
- **THEN** 参加者画面に第 1 問の問題名・説明・全選択肢の写真と選択肢の説明が表示順に、および「STAGE 1」が表示される

#### Scenario: 3 択の問題で 3 つの選択肢を表示する
- **WHEN** 会場が選択肢 3 個の問題を表示する
- **THEN** 参加者画面に 3 つの選択肢が、問題データに書いた順に写真と選択肢の説明つきで表示される
